# Homework Assignment: Camera Pose Estimation via Epipolar Geometry

## 1. 核心目标与问题定义

* **作业目标**：实现一个基于对极几何的相机位姿估计完整流水线。
* **具体任务**：给定同一场景不同视角的两张图像，使用基础矩阵或本质矩阵分解来计算两个相机位置之间的相对位姿（包含旋转和平移）。
* **截止时间**：作业发布日期的三周后。
* **输入数据**：同一场景的两张图像 $(I_{1},I_{2})$，以及可选的相机内参标定矩阵 $K_{1}$ 与 $K_{2}$。
* **输出数据**：相对位姿 (R, t)，其中 $R\in SO(3)$ 表示 3x3 旋转矩阵，$t\in\mathbb{R}^{3}$ 表示 3x1 平移向量（仅能确定尺度）。

---

## 2. 算法总体流程

1. **特征提取与匹配**：在两张图像之间寻找对应点。
2. **基础矩阵估计**：结合 RANSAC 与 8 点法计算基础矩阵 F。
3. **本质矩阵计算**：在已知相机内参的情况下，利用公式 $E=K_{2}^{T}\times F\times K_{1}$ 计算本质矩阵 E。
4. **位姿分解**：通过奇异值分解（SVD）从本质矩阵 E 中提取出旋转矩阵 R 和平移向量 t。
5. **位姿消歧**：使用手性检查（cheirality check）选出正确的位姿解。
6. **三角测量**：通过 3D 点云重建验证结果。

---

## 3. 具体实现任务说明

### 3.1 数据准备与特征匹配
* **数据源**：可使用提供的图像对，也可通过代码生成三维点云的合成数据进行验证。
* **特征匹配**：提取 SIFT 或 ORB 特征，使用 FLANN 或暴力匹配器（brute-force matcher）进行匹配，并通过比率测试（ratio test）过滤掉低质量匹配。

### 3.2 矩阵估计与计算
* **基础矩阵 (F)**：需实现 Hartley 归一化（平移质心至原点，缩放使平均距离为 $\sqrt{2}$）。接着使用归一化 8 点法，通过 SVD 求解 $Af=0$，并强制将最后一个奇异值设为 0 以满足秩为 2 的约束。最后进行反归一化。为了提升鲁棒性，需结合 RANSAC 算法并利用 Sampson 距离计算样本内点。
* **本质矩阵 (E)**：根据公式 $E=K_{2}^{T}FK_{1}$ 转换得到。必须强制约束其奇异值为 $[\sigma,\sigma,0]$（将前两个奇异值设为 1，最后一个设为 0）。

### 3.3 位姿分解与消歧
* **提取候选解**：对本质矩阵进行 SVD 分解 $E=Udiag(1,1,0)V^{T}$，提取四个可能的 (R, t) 解。其中旋转矩阵 $R_{1}=UWV^{T}$ 或 $R_{2}=UW^{T}V^{T}$，平移向量为 $t=\pm u_{3}$（U的第三列）。
* **线性三角测量**：对于每对匹配点使用 DLT 方法构建矩阵 A，并通过 SVD 求解 $AX=0$ 得到齐次坐标下的 3D 点。
* **确定最终位姿**：对四个候选位姿进行三角测量，通过手性约束判断，选择能够产生最多处于摄像机前方（正深度）3D点的位姿作为最终解。

## 4. 预期输出与可交付成果

### 4.1 预期输出内容
* **图像输出**：特征匹配连线图、图像对上的对极线可视化。
* **数值输出**：计算所得的基础矩阵 F、本质矩阵 E、旋转矩阵 R 以及平移向量 t。
* **误差指标**（若有真实参考值）：需计算旋转误差 $\theta=arccos(\frac{trace(R_{gt}^{T}R_{est})-1}{2})$ 和平移角度误差 $cos^{-1}(t_{gt}\cdot t_{est})$。
* **可选输出**：三角测量得到的 3D 点云重建图。

### 4.2 提交文件结构要求 (ZIP 压缩包)

* `pose_estimation.py`: 包含所有函数的主体实现代码。
* `run_pose_estimation.py`: 用于运行完整算法流水线的脚本。
* `requirements.txt`: Python 环境依赖列表。
* `test_data/`: 包含测试图像对、相机内参以及评估用的真实位姿数据。
* `results/`: 包含估计位姿文本文件 `pose_results.txt`、匹配与对极线可视化截图 `feature_matches.png` / `epipolar_lines.png`、误差分析文本 `error_analysis.txt` 及可选的3D重建图。
* `report.pdf`: 不超过 3 页的报告，需包含实现细节、不同算法对比、误差分析以及局限性讨论。

## 6. 进阶加分项 (Bonus)

1. **7 点法**：实现用于估计基础矩阵的 7 点算法。
2. **归一化对比**：对比带有归一化与不带归一化的 8 点法之间的性能差异。
3. **非线性优化**：利用光束法平差（Levenberg-Marquardt）对位姿进行微调。
4. **5 点法**：实现 Nister 5 点法以计算本质矩阵。
5. **直接计算 E**：当已知相机内参时，跳过基础矩阵 F 直接估计相对位姿。
6. **不确定性传播**：估算并传播预测位姿的协方差矩阵。
7. **平面场景处理**：使用单应性矩阵分解（Homography decomposition）来处理平面场景。
